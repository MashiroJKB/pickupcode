# 「取件码」Android 原生应用 (`PickupCode`)

一款专为校园场景打造的极简、高颜值 Android 本地取件码管理工具。基于 **Kotlin + Jetpack Compose + Room + DataStore** 开发，原生支持 **120Hz 高刷新率**，视觉与交互对标 **Apple Human Interface Guidelines (HIG)** 与 **Liquid Glass（液态玻璃）** 设计规范。

---

## ✨ 核心功能（v1.1.4）

1. **100% 纯本地离线隐私保护**
   - 应用绝不申请 `INTERNET` 联网权限，所有快递短信仅在手机本地通过正则解析引擎提取并存储于 Room 数据库，不上传任何数据。
2. **「淘宝身份码」与「菜鸟身份码」双开关快捷入口**
   - 在设置页提供独立的「淘宝身份码」与「菜鸟身份码」开关控件，支持**单独开启或同时开启**。
   - 开启后首页顶部即展示对应的液态玻璃快捷 Banner，点击直接唤起手机淘宝对应驿站身份码页扫码出库。
3. **按快递房分组与自然数字从小到大排序**
   - 内置校园快递房默认规则（`① 家属区1号 京东`、`② 家属区2号`、`③ 家属区3号`、`⑤ 田径场5号 顺丰`、`⑥ 田径场6号 极兔`、`⑦ 田径场7号 中通`）。
   - 同一快递房内的取件码自动按货架号、层号、包裹序号**从小到大自然排序**（如 `1-4-...` < `2-1-...` < `30-3-...` < `94-3-...` < `100-1-...`）。
   - 取件码采用高辨识度等宽特粗字体一行完整显示；下方支持点击备注商品名称；右侧提供 `⋮` 竖点菜单（查看原始短信全文、切换归属快递房或删除）。
4. **多选「确认已取」与 3 秒内「撤销已取」**
   - 点击取件码左侧圆圈可多选勾选，底部中央自动弹出「确认已取」按钮；点击后已取包裹立即从待取列表消失，并在同一位置提供 3 秒内可点击的「撤销已取」按钮。
5. **自动扫描最近 7 天短信 & 7 天内已取记录管理**
   - 每次打开应用（冷启动与热启动）自动扫描最近 7 天快递短信，自动过滤验证码与营销信息，支持「一信多码」自动拆分。
   - 已取快递记录在本地保留 7 天以自动排除重复扫描入库，满 7 天自动清理；在设置页点击「7天内已取」卡片可随时查看明细并支持一键恢复回待取列表。
6. **简洁二级「识别规则」管理**
   - 设置页「识别规则」一级列表简洁展示各快递房名称，支持自由**添加/删除快递房**；点击圆形编辑笔图标即可在居中弹窗中修改快递房名称、新增及管理详细匹配关键词。

## 🛠️ 构建与测试

1. **构建 R8 优化版 Release APK**：
   ```powershell
   ./gradlew assembleRelease
   ```
   构建产物位于 `app/build/outputs/apk/release/app-release.apk`。
2. **运行单元测试**：
   ```powershell
   ./gradlew testDebugUnitTest
   ```
