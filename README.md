# 「取件码」Android 原生应用 (`PickupCode`)

一款专为校园场景打造的极简、高颜值 Android 本地取件码管理工具。采用 **Kotlin + Jetpack Compose + Room + DataStore** 开发，支持 **120Hz 高刷新率**，视觉与交互对标 **Apple Human Interface Guidelines (HIG)** 与 **Liquid Glass（液态玻璃）** 现代风格。

---

## 核心特性

1. **100% 纯本地离线隐私保护**
   - `AndroidManifest.xml` **不申请 `INTERNET` 联网权限**，所有短信内容均在本地通过正则解析引擎提取并存储于 Room 数据库，绝不上传任何数据。
2. **顶部「淘宝身份码 / 扫码出库」快捷液态玻璃卡片**
   - 定向拉起手机淘宝身份码页面，支持在设置中自由切换「淘宝出库码（默认）」与「菜鸟出库码」。
3. **按快递房分组与自然数字排序**
   - 自动将取件码按快递房（`①` `②` `③` ...）归类展示；同一快递房内的取件码严格按货架号、层号、包裹序号**从小到大自然排序**（如 `1-4-...` < `2-1-...` < `30-3-...` < `94-3-...` < `100-1-...`）。
   - 取件码采用室外强光高辨识度等宽特粗字体一行完整展示，下方支持一键备注商品名称，右侧提供 `⋮` 更多操作按钮（查看原始短信全文、切换归属快递房或删除）。
4. **多选「确认已取」与 3 秒内「撤销已取」**
   - 支持多选勾选取件码，勾选时底部中央弹出「确认已取」按钮；点击后已取包裹立即从待取列表消失，并在同一位置提供 3 秒内可点击的「撤销已取」按钮。
5. **每次打开自动扫描与 7 天防重机制**
   - 冷启动与热启动切回前台时自动扫描最近 7 天的快递短信，自动过滤验证码与营销信息，支持「一信多码」自动拆分。
   - 已取快递记录在本地保留 7 天用于自动去重排除（防止重复扫描入库），满 7 天自动清理。
6. **自定义「识别规则」**
   - 支持在设置页自由**添加/删除快递房**，并为各快递房自定义名称与匹配关键词。

## 构建方式

1. **本地构建 Release APK**：
   ```powershell
   ./gradlew assembleRelease
   ```
   构建产物位于 `app/build/outputs/apk/release/app-release.apk`。
2. **单元测试**：
   ```powershell
   ./gradlew testDebugUnitTest
   ```
