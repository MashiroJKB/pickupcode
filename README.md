# 「取件码」(`PickupCode`)

一款极简的 Android 本地取件码管理工具。纯本地离线运行，自动提取短信或截图中的取件码，并按快递房与货架号排序整理。

## ✨ 基础功能

- **纯本地离线识别**：不申请联网权限，每次打开自动扫描最近 7 天快递短信，支持一信多码拆分并过滤验证码与营销信息；新增「截图解析」，通过系统照片选择器仅读取单次勾选图片，离线 OCR 提取并导入待取包裹。
- **快递房分组与自然排序**：支持自定义快递房名称、前置序号、关键词与拖动排序；同一快递房内按货架号从小到大排序，超时包裹显示滞留天数提醒。
- **快捷取件与批量管理**：勾选待取圆圈时左上角自动切换为「全选」一键选中全部；支持底部「确认已取」与红色垃圾桶批量删除、左滑/长按快捷操作，以及 3 秒内「撤销已取」；支持查看并恢复 7 天内已取记录、手动输入/粘贴短信解析与识别规则导出/导入。
- **图片分享取件码**：进入分享模式可一键「全选」待取包裹，生成高清分组清单图片快速分享至微信等应用，并支持在弹窗内勾选「分享备注 / 不分享备注」。
- **身份码快捷入口与桌面同步**：支持开启「淘宝」「菜鸟」「拼多多」身份码/取件码入口；提供桌面小组件展示待取码与一键核销，开启通知与桌面角标权限后同步显示待取件数。

## 🎨 外观介绍

- **液态玻璃视觉风格**：采用通透磨砂分层质感与弹性微交互动效，首页顶栏「设置」仅保留极简齿轮图标，搭配左下「已取记录」、底部确认/删除操作栏与右下快捷添加按钮保持对称视觉。
- **深 / 浅色模式自适应**：应用界面及正方形线性包装箱桌面图标均跟随系统深/浅色模式自动切换。
- **紧凑并排身份码栏**：同时开启 2～3 个身份码入口时，顶部自动切换为「身份码/取件码」紧凑并排圆角方块，释放首屏空间展示更多待取包裹。
