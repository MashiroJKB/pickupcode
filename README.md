# 「取件码」Android 原生应用 (`PickupCode`)

一款专为校园场景打造的极简、高颜值 Android 本地取件码管理工具。基于 **Kotlin + Jetpack Compose + Room + DataStore** 开发，原生支持 **120Hz 高刷新率**，视觉与交互对标 **Apple Human Interface Guidelines (HIG)** 与 **Liquid Glass（液态玻璃）** 设计规范。

---

## ✨ 核心功能（v2.1.0）

1. **100% 纯本地离线隐私保护**
   - 应用绝不申请 `INTERNET` 联网权限，所有快递短信仅在手机本地通过正则解析引擎提取并存储于 Room 数据库，不上传任何数据。
2. **极简全正方形深浅双色自适应应用图标 & 应用界面系统级深/浅色自动切换**
   - 应用图标采用高清全幅正方形 PNG（兼容 OriginOS 等定制系统大图标底色一致显示）：浅色模式为纯白底色配黑色等距快递盒线条，深色模式自动反转为纯黑底色配白色线条。
   - 应用界面完整支持**系统深/浅色模式自动切换**（随系统夜间模式实时切换深邃曜石黑与清透浅白液态玻璃界面、状态栏/导航栏图标对比度、启动窗口背景及桌面小组件外观）。
3. **「淘宝身份码」、「菜鸟身份码」、「拼多多取件码」品牌图标 & 紧凑并排模式**
   - 全部采用对应高清品牌应用图标并统一按 Apple 连续圆角（Squircle）裁剪；在设置页提供三个独立开关控件。
   - 当仅开启 1 个开关时展示完整液态玻璃 Banner；当同时开启 2 个或 3 个时，自动切换为标题为「身份码/取件码」的**紧凑型并排液态玻璃方块按钮**，仅展示应用图标，让首屏直接露出更多取件码。
4. **桌面液态玻璃小组件（App Widget）、首次打开通知/角标授权引导 & 桌面未读角标**
   - 支持添加**桌面液态玻璃小组件**，无需打开 App 即可在手机桌面直接按货架顺序浏览待取件码、一键标记「已取」，或一键拉起淘宝/菜鸟/拼多多。
   - 首次打开自动请求通知权限（Android 13+）并弹出「通知与桌面角标」权限引导，支持一键跳转系统通知管理开启桌面图标角标，根据当前待取快递件数实时同步角标。
5. **按快递房分组、自然数字从小到大排序 & 滞留天数提醒角标**
   - 内置校园快递房默认规则（`① 家属区1号 京东`、`② 家属区2号`、`③ 家属区3号`、`⑤ 田径场5号 顺丰`、`⑥ 田径场6号 极兔`、`⑦ 田径场7号 中通`）。
   - 同一快递房内的取件码自动按货架号、层号、包裹序号**从小到大自然排序**（`1-4-...` < `2-1-...` < `30-3-...` < `94-3-...` < `100-1-...`）。
   - 自动根据短信到达时间计算停留时长，超过 24 小时或 48 小时的包裹在取件码旁显示柔和的橙色/红色**「已到 N 天」**提醒标签。
6. **120Hz 优雅左滑快捷操作、长按快捷菜单 & 多选「确认已取 / 3秒撤销」**
   - **左滑快捷操作**：单条取件码支持 iOS 级 GPU 丝滑左滑与弹性阻尼动画，伴随视差缩放展开绿色的「已取」与红色的「删除」按钮（点击「已取」支持底部 3 秒「撤销已取」）。
   - **长按快捷弹窗**：长按任意取件码直接弹出「已取」与「删除」大按钮。
   - **多选与 3 秒撤销**：点击左侧圆圈支持多选勾选，底部中央弹出「确认已取」；点击后立即消隐并在同位置提供 3 秒内可点击的「撤销已取」按钮。
7. **自定义快递房序号/实心圆、长按拖动排序 & 规则口令一键导出/导入**
   - 设置页「识别规则」支持**按住快递房卡片上下拖动排序**，主页与桌面小组件展示顺序实时同步。
   - 支持自定义快递房前缀圆圈序号（输入 `1` 显示 `①`，留空则渲染为等大实心圆 `●`）。
   - 支持**「导出规则口令」与「导入规则口令」**，一键复制识别规则口令分享给同校同学，粘贴即可导入整套驿站规则。
8. **自动扫描最近 7 天短信 & 7 天内已取记录管理**
   - 每次打开应用（冷启动与热启动）自动扫描最近 7 天快递短信，自动过滤验证码与营销信息，支持「一信多码」自动拆分。
   - 已取快递记录在本地保留 7 天以自动排除重复扫描入库，满 7 天自动清理；在设置页点击「7天内已取」卡片可查看明细并支持一键恢复回待取列表。

## 🛠️ 构建与测试

1. **构建 R8 优化版 Release APK**：
   ```powershell
   ./gradlew assembleRelease
   ```
   构建产物位于 `app/build/outputs/apk/release/app-release.apk`。
2. **运行单元测试**：
   ```powershell
   ./gradlew testDebugUnitTest
   ```
