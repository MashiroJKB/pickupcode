# 「取件码」(`PickupCode`)

一款极简的 Android 本地取件码管理工具。纯本地离线运行，自动提取短信中的取件码并按快递房与货架号排序整理。

## ✨ 基础功能

- **纯本地离线解析**：不申请联网权限，每次打开自动扫描最近 7 天快递短信，支持一信多码拆分并过滤验证码与营销信息。
- **快递房分组与自然排序**：默认预设 1～8 号快递房规则，支持自定义名称、前置序号、关键词与拖动排序；同一快递房内按货架号从小到大排序，且可在首页任意快递房卡片右上角点击「+」直接添加包裹到该快递房。
- **快捷取件与批量管理**：勾选待取圆圈后左上角切换为「全选」、右上角切换为「取消」，可一键全选/退出勾选或直接点击「分享取件码」；支持底部「确认已取」与红色垃圾桶批量删除、左滑/长按快捷操作，以及 3 秒内「撤销已取」；支持查看并恢复 7 天内已取记录、手动输入/粘贴短信解析与识别规则导出/导入。
- **图片分享取件码**：支持未勾选时进入选择模式或勾选状态下直接点击「分享取件码」，生成高清分组清单图片发送至微信等应用，并支持在弹窗内勾选「不分享备注 / 分享备注」。
- **身份码快捷入口与桌面同步**：支持开启「淘宝」「菜鸟」「拼多多」身份码/取件码入口；提供桌面小组件展示待取码与一键核销，开启通知与桌面角标权限后同步显示待取件数。

## 🎨 外观介绍

- **液态玻璃视觉风格**：采用通透磨砂分层质感与弹性微交互动效，首页顶栏「设置」仅保留极简齿轮图标，底部搭配确认已取、对称红色删除按钮与右下快速添加按钮，布局平衡统一。
- **深 / 浅色模式自适应**：应用界面及正方形线性包装箱桌面图标均跟随系统深/浅色模式自动切换。
- **紧凑并排身份码栏**：同时开启 2～3 个身份码入口时，顶部自动切换为「身份码/取件码」紧凑并排圆角方块，释放首屏空间展示更多待取包裹。
