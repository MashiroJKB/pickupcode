# 「取件码」(`PickupCode`)

一款极简的 Android 本地取件码管理工具。纯本地离线运行，自动提取短信取件码并按快递房与货架号排序整理。

## ✨ 基础功能

- **纯本地离线扫描**：不申请联网权限，每次打开自动扫描最近 7 天快递短信，支持一信多码拆分并过滤验证码与营销信息。
- **快递房分组与自然排序**：支持自定义快递房名称、前置序号、关键词与拖动排序；同一快递房内按货架号从小到大排序，超时包裹显示滞留天数提醒。
- **快捷取件与批量删除**：支持勾选「确认已取」、底部红色按钮批量删除、左滑/长按快捷操作，以及 3 秒内「撤销已取」；支持查看并恢复 7 天内已取记录、手动添加或粘贴短信解析，以及识别规则口令导出/导入。
- **分享取件码**：支持进入分享模式一键「全选」待取包裹，以分组清单图片或纯文本形式快速分享至微信等应用。
- **身份码快捷入口**：支持开启「淘宝身份码」、「菜鸟身份码」、「拼多多取件码」入口，多个开关同时开启时自动切换为紧凑并排模式。
- **桌面小组件与角标**：提供桌面小组件展示待取码与一键核销，并在开启通知与桌面角标权限后同步显示待取件数。
- **深 / 浅色模式自适应**：界面与正方形应用图标随系统深/浅色模式自动切换。
